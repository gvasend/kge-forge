# A2.4 — Responses-API Governed Reasoning Integration

Status: **PARTIAL; implementation present, real model qualification unavailable**

`adapter/responses_orchestrator.py` implements a thin caller-owned Responses API
client. It requests no built-in tools and supplies only strict function entries
for the A2.3 governed action vocabulary. Returned function calls are converted to
versioned ActionRequests and dispatched through `ReasoningOrchestrator`, which
binds authorization, validates independently, records audit, and returns an exact
function-call output. The API response ID, model call ID, ActionRequestId, and
GovernedInvocationId are retained by the orchestrator; no credentials enter model
context, governed execution, or audit.

The exact supplied registry is generated by `tool_definitions()` and contains only:
governed_read, governed_list, governed_search, governed_write, governed_patch,
governed_exec, governed_status, governed_git_status, governed_git_diff,
authority_expansion_request, and finish_task. No shell, local shell, code
interpreter, web search, file search, MCP, plugin, browser, or image tool is
requested. `parallel_tool_calls` is disabled and the loop is bounded to eight
cycles. Transport retries cannot duplicate effects because A2.3 replay protection
keys results by call ID.

The caller-owned registry contract test passes. A real no-tool Responses request
was attempted against `https://api.openai.com/v1/responses` with model `gpt-5.4`
and `store=false`, but did not return within the bounded qualification window in
this environment. No real model tool call or autonomous scratch programming loop
was therefore executed. This leaves real-model integration, API continuation,
credential/network observation, and end-to-end tool provenance unqualified.

The installed Codex app-server remains excluded permanently. A2.1 execution-scope
quiescence remains open. No E1-WP-001 implementation or product-repository change
was made. A later authorized qualification must run the real API loop with a
reachable approved endpoint, then exercise denial, escalation, replay, prompt
injection, and scratch programming scenarios before closing A2.4.
